Chapter II
Pipeline

Behind the scenes

Generations are slow and the providers are unreliable, so nothing runs inside a web request. Every generation is a job that survives a server restart.

Validate

The API route checks the request and confirms the user owns the project.

Enqueue

A service writes a pending generation row and queues a job in Redis via Bull.

Render

A worker calls the provider, retrying automatically, and stores the result.

Deliver

The frontend polls until the generation completes, then shows the asset.

Per-user hourly rate limits, a daily generation cap and Joi validation protect the API bills from runaway usage.
