# Brand font: HEBRA

The brand name is set in **Hebra**, a commercial font (Flawlessandco). Its free
download is for personal use only, so the font files are not committed here.

To turn it on, buy a license and drop the web files into this folder:

```
fonts/Hebra-Regular.woff2
fonts/Hebra-Regular.woff
```

`css/style.css` already loads them through `@font-face`, so you don't need to
change any code. Until the files are here, the site falls back to **Michroma**
(Google Fonts), a similar wide, geometric sans serif.
